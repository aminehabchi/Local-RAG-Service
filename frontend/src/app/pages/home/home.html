How it works

RAG in three stages — ingest, retrieve, generate.

Ingest

PDF / TXT → chunked → embedded with BAAI/bge-small-en-v1.5 (384d) → stored in PostgreSQL + pgvector

→

Retrieve

Query embedded → cosine similarity via <=> operator or full-text search or hybrid RRF

→

Generate

Top-k chunks injected as context → LLM (Ollama / OpenAI / Anthropic / Custom) answers grounded in your data
